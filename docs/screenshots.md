# Project CBM Screenshot Gallery

## Project CBM v1.2.0

Screenshots of the released v1.2.0 Menu and VICE BASIC screens, plus Project CBM
Splash / Cover artwork. Click any image to open it at full size. Private network
details in the Main Menu and Network screenshots were redacted by the owner.

These images illustrate the interface; they do not add hardware qualification
claims. The Model 5 / 500 branding is artwork, not evidence of qualification on
those models. See the [current manual](release/user-guide.md) for release behavior.

For instructions on taking screenshots, see [Screenshots from SSH](release/screenshots.md)
and the [capture checklist](release/screenshot-checklist.md).
[Historical v1.0.0 screenshots](#historical-v100) are retained below.
