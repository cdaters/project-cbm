# Project CBM 1.1 release contents and notices

[Documentation index](../README.md) · [Software components](software-components.md)

This records the owner's release decisions for Project CBM 1.1.0. It does not turn
uncertain third-party rights into a new license or claim that the release is published.

## Project CBM code and artwork

Project CBM code and documentation use their existing MIT license. Craig Daters
created and owns the Project CBM logos, primary branding artwork and seven machine
Covers. He authorizes their inclusion and redistribution as part of Project CBM
1.1.0. The Menu package records this separately from its MIT code license.
The artwork permission is release-specific; it is not a blanket MIT license for
separate distribution or modification of branding or Covers. Their existing bytes,
filenames, mappings and recorded hashes remain unchanged.

## CCGMS and other bundled applications

The CCGMS 2021 application disk contains only the unchanged verified CCGMS PRG from
Alwyz's published release. The BSD 3-Clause notice, original attribution, published
source and provenance are included. Seven unrelated compilation files are excluded.
The source accompanies the same upstream release; a bit-identical source rebuild
has not been established. Project CBM modifies the disk composition, not the program.

StrikeTerm is omitted from the new release composition by owner product choice in
favor of CCGMS. This is not a finding that StrikeTerm redistribution is prohibited.
Historical candidates and review evidence remain unchanged. Generic user-supplied
C64 disk support does not require StrikeTerm-specific product code.

SID-Wizard remains the previously reviewed core subset. Additional songs, demos,
games and separately supplied qualification media are not silently bundled.

## VICE ROMs and resources

Retain only the ROM/resource material from the established pinned upstream VICE
distribution used by Project CBM, including notices and exact provenance. VICE's
GPL-covered program code and Commodore/DTV ROM copyrights have different rights bases.
Upstream inclusion is not a claim that the ROMs are GPL or freely licensed.

The retained evidence has not located a blanket GPL grant for those ROMs. The owner
accepts that known historical permission-documentation uncertainty for 1.1.0; it is
not by itself a release blocker. Do not reopen open-ended rights research unless new
affirmative contrary evidence materially changes the assessment. A specific rights-holder
objection would be evaluated on its actual facts. No independently sourced proprietary
ROM collection is added under this decision.

## Verification and later work

For 1.1.0 provide SHA-256 image checksums, exact source/release identities, useful
package/component inventories and applicable license/source notices. Publication and
final release tags require separate owner authorization and physical qualification.

Cryptographic release signing, a standardized SPDX/CycloneDX software bill of materials,
and complete public source-to-image bootstrap are **post-1.1.0 work**, not release
blockers. Do not call an unsigned release signed or a package inventory a complete
standardized SBOM. Build Your Own documentation must state its current limitations.
The final image, end-user instructions, safe composition and source/notices remain
release priorities.
