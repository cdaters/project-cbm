# Search and download software from Assembly64

**Powered by Assembly64** — [official website](https://assembly64.hackerswithstyle.se).
Assembly64 is an independent project and external service. Project CBM integrates
its API; it does not own Assembly64 or imply any wider affiliation.

1. Open **CONTENT → Online Library**. Searching and downloading need Internet access.
2. Enter a search and choose supported filters such as Group, Year, Repository or
   Category. Back returns without discarding your other choices; Clear filters
   starts a fresh search. Available values come from the service.
3. Open a result to read its details and view downloadable files. Select the files
   you want; include every disk required by a multi-disk title.
4. Choose the destination and review the files before **Save to Library**. Files
   go below `/home/pcbm/content/<category>/<machine>/Downloaded/<collection>`.
5. Read the result, then use **CONTENT → Browse Library** to find saved software.
   Downloads do not automatically launch. Once saved, ordinary local content remains
   available offline; its machine/drive requirements still apply.

**Already Present** means matching file bytes already exist at the intended
location. **Keep Both** preserves different existing content and uses a numbered
collection folder for the new copy. It does not overwrite your edited disks.
A cancelled or failed operation can leave completed files saved; read the result
before retrying. Only download content you are entitled to use.

**Server Information** shows the selected Assembly64 Central service and its public
server directory. Refresh updates that information; Back returns. Listed home/public
servers are informational in 1.2.0, not interchangeable selectable sources. A service
error remains visible with Retry/Back; there is no automatic FTP or alternate-server
fallback. No Assembly64 collection is bundled with Project CBM.
