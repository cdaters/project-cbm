# Screenshots

This folder contains screenshots used by the Project CBM README and documentation.
Screenshots are organized by release version.

- `v1.2.0/`: 16 owner-supplied PNG exports for the released v1.2.0. The Main Menu
  and Network exports have owner-applied privacy redactions. Repository copies
  preserve the supplied filenames and exact bytes. The splash is Cover artwork;
  the machine images show running VICE at BASIC.
- `v1.0.0/`: preserved historical screenshots and Cover artwork.

Browse the [Screenshot Gallery](../docs/screenshots.md). For capture instructions,
see [Screenshots from SSH](../docs/release/screenshots.md) and the
[capture checklist](../docs/release/screenshot-checklist.md).
